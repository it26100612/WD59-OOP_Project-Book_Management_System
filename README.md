# BookNest – Online Bookstore Management System

## Project Overview

BookNest is an Online Bookstore Management System developed as a group project for the SE1020 Object-Oriented Programming (OOP) module.

The system provides an online platform where customers can browse books, manage their accounts, place orders, and submit reviews. Administrators can manage books, categories, users, and orders.

## Project Objectives

- Develop an online bookstore management system.
- Apply Object-Oriented Programming concepts using Java.
- Implement CRUD operations.
- Use file handling for data storage.
- Develop a responsive and user-friendly interface.
- Practise collaborative software development using GitHub.

## Development Approach

The project is developed collaboratively by six members. Each member is responsible for a specific system module.

GitHub is used for source code management, collaboration, and tracking individual contributions through commits.

## Data Storage

The system uses file handling to store and retrieve application data from text files instead of relying on a database.
